# Duct Checker Pro 5.02 — design brief

Native offline iPhone/iPad engineering utility. SwiftUI, iOS 17+; SF Pro via system fonts.
English and SI on first launch, independent of device settings. Persist preferences.
User-approved direction: glassmorphism; original PNG logos only; no decorative duct drawings.

Tokens: system backgrounds/primary/secondary labels, blue accent from Duct logo;
spacing 8/12/16/24/32 pt; input corners 8, result panel corners 24;
body .body, headings .title2, main result .largeTitle with monospaced digits.
Signature: one prominent result on a frosted panel above quiet detail rows.
Native tabs and navigation; no animation required. Reduce Transparency replaces glass with
opaque system background. Dynamic Type, scrollable forms, 44 pt controls and labeled fields.
No artificial shadows behind logos; preserve full aspect ratio and original pixels.

Screens: Duct Size (check existing / size by target velocity), Convert (both directions,
fixed width in reverse, separate area/friction methods), Diffuser / Air Grille (preliminary
free-area sizing), Settings (five languages, SI/US), About (company, original logo, website).
